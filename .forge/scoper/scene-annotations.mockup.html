Hide notes & dimensions per scene — the ANNOTATIONS column, rev 2

Rev 1 proposed sets only. The live probe (below) proved both ways of hiding work, and proved one thing does not: SketchUp will not hide Untagged. So this revision is one picker that handles sets and single callouts together, with no sorting required first. real = lifted from the shipped tool; observed = the probe; illustrative = example scenes, sets and callouts invented for this page.

Orange dashed strips are for Benton and are not part of the dialog. Click around the picker — tick a set, expand it, tick loose callouts, try all / none, USE MY SELECTION, “New set…”. Then answer the questions and copy the box at the bottom back into the chat.

  • A scene remembers a hidden set (a tag) — hide 300 texts with one tick, reuse it across scenes, and Client-safe knows about it.
  • A scene also remembers one hidden callout — screen text, leader text, a dimension, a 3D label — through the exact call the walls picker uses. No sorting first.
  • The camera is untouched by that save, same guarantee as walls.
  • Untagged cannot be hidden. Most hand-placed text sits on Untagged, so a sets-only picker would have listed empty sets and left the real callouts alone. That is why loose callouts get their own rows — and why the picker never offers an “Untagged” set that would silently do nothing.

Notes & dimensions hidden in “03-side”
Ticked = hidden when this scene exports. Sets hide as one; loose callouts hide one by one — both are saved into this scene only.
The picker. One list, one rule. Set rows hide a whole tag; the arrow opens a set to reach single callouts inside it; NOT IN A SET lists every loose callout (Untagged first) with all · none so a batch is still one click. Members grey out while their set is ticked.

What each control does

Hide notes
Opens the picker for that row and switches the viewport to that scene, like Hide walls. Cancel returns to the scene you were on.
Set row
Tick = the whole tag hidden in this scene. Saved with the scene's own tag visibility; SketchUp's Tags panel shows the same thing.
Callout row
Tick = that one text / dimension / 3D label hidden in this scene, saved the way a hidden wall is. Works on Untagged text, which no set can reach.
all · none
Ticks or unticks every row in that group. NOT IN A SET → all → Apply is the zero-setup batch hide.
USE MY SELECTION
Click callouts in the model first; this ticks their rows. If they all belong to one set it says so and offers the set. Adds, never unticks.
SHOW ME
Selects and zooms to the set's contents or to that one callout.
MOVE SELECTION INTO A SET
Optional. Re-tags selected callouts into an existing or new set for reuse across scenes and for Client-safe coverage. Membership is for every scene; walls in the selection are refused by name.
Export
Nothing new. Both lanes select each scene before capturing it, and a scene re-asserts both its tag state and its hidden callouts. Client-safe hides everything regardless.
