A′ · alternativeSame three, height pushed out to the side instead of the rear

For a booth backed 1" off a wall (the house convention), a rear push buries the height line in the wall. Pushing it sideways keeps it in the room, but it then shares a corner with the depth line, so it goes out 1.5× further (36") and the two witness lines overlap on the ground. Which of A / A′ your reference image is, I could not tell from the description — see Q3. The tool can pick A′ automatically when something sits within 24" behind the booth.

The tool will measure all three off the built parts and print the catalogue comparison beside them. A mismatch over 1/4" is said out loud, never hidden — the dimension always reads what is drawn, because that is what SketchUp prints on it.

How it is used

Click the panel button, then click the booth. The cursor becomes a pick; click any part of a WhisperRoom and the three strings appear. Esc cancels. If a booth is already selected when you press the button, it skips the pick.
No dialog, no settings. No Standard/Enhanced choice (that was a way to draw the wrong height), no vents box, no label above the booth. The console still prints the reconciliation.
Click it again and it re-measures. Each booth carries its own set; re-running on booth 1 never touches booth 2. A second button, Clear WhisperRoom dimensions, removes one booth's set (pick it) or all of them (Esc).
Tag WR-Dims-Booth, plain black. Same tag name as today, so the proposal package, the ANNOTATIONS picker and client-safe already know it. The orange on today's tag only ever showed under Color-by-Tag; the dimensions themselves have always drawn in the model's dimension colour, which is why your image is black.
