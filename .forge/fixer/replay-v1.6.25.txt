=== 8. what this harness CANNOT see ===============================

    only SketchUp can answer whether ENH deck parts carry a bracket
    line at all. Where they do not, the code falls back to the same
    positional rule the Standard deck uses for symmetric panels.
  - contact_z, deck_extent, the real bounding boxes: not used by the
    IEP path (it seats off the placed Standard deck), but they are
    why nothing here is evidence about the Standard path.
  - whether the placed inner deck actually clears the inner walls.
  - the FLOOR SEAM SEAL'S HEIGHT. wr-deck.rb derives it (top face
    flush with the deck top) and warns by name on every build. The
    part geometry above says what it would land on; only a fit test
    says whether that is where it belongs.
  - whether the ENH tray lip really is a lip. The measurement is
    unambiguous - +1 per outer edge across all 44 parts - but that it
    is the engulfing overhang rather than something else is read off
    Benton's own sentence about the tray, not off the geometry.
