# Proposal brand — quick reference

**The newest shipped pack in `C:\Users\bento\Desktop\ProposalFiles\<Client>\` is the standard.**
Read it before every build. As of August 2026 that is
`ProposalFiles\David Smith\David-Smith-Booth-Renderings.pdf`.

> ⚠️ `WhisperRoom Proposals\docs\PROPOSAL-GUIDELINES.md` describes the **original landscape
> v1 format** and has been superseded. It still says "US Letter landscape, centered orange
> title." That is not what ships any more. Don't build from it.

## What actually ships (verified against the David Smith pack)

- **US Letter portrait, 8.5 × 11 in** — 612 × 792 pt. Not landscape.
- 1 cover + N content pages, **one render per page**. David Smith is 5 pages, 2.73 MB.
- Generated by `WhisperRoom Proposals\build-v2.js` from a `proposal-v2.json`.
  Copy the newest `examples\<client>\proposal-v2.json` and edit it. Never hand-build a layout.

## Cover page

1. **Header** — WhisperRoom wordmark top-left with letter-spaced `SOUND ISOLATION ENCLOSURES`
   beneath it; top-right a three-line grey letter-spaced block: doc type / client / month year.
   Horizontal rule under both.
2. **Eyebrow** — orange, letter-spaced caps (e.g. `BOOTH RENDERINGS`).
3. **Headline** — large and bold, two lines, two-tone: lead line in near-black
   (`Sound isolation for`), client name in brand orange. Left-aligned, not centered.
4. **Hero render**, full content width.
5. **Caption** — orange bold lead-in, then grey body (`captionLead` + `caption`).
6. **Three-card spec strip** in a bordered box: `BOOTH` / `ROOM` / `IN THIS PACK`, each a
   letter-spaced grey label with a value and a sub-line.
7. **Callout** — light grey panel with an orange left rule, bold lead-in
   (`About these renderings.`) then body.
8. **Footer.**

## Content pages

1. **Header** — same logo block left; top-right three lines: `BOOTH n OF n` / booth name /
   `PAGE 0n / N` with the page number in orange bold. Rule beneath.
2. **Section line** — short orange bar, orange section number (`01`), then the title in bold
   letter-spaced caps. Right-aligned grey letter-spaced descriptor on the same line.
3. **Lead paragraph** with a bold lead-in.
4. **Render** inside a thin bordered box.
5. **Caption** — `Image 0n` in orange bold, then grey body text.
6. **Footer.**

## Footer (every page)

## Color and type

| Role | Value |
|---|---|
| Brand orange | `#ee6216` |
| Ink | near-black |
| Labels / meta | grey, uppercase, letter-spaced |
| Family | system grotesque (Arial/Helvetica); bold, tight-tracked headline |

No second accent color without a branding decision.

## Render sequence (David Smith, 5 plates)

exterior in the finished room → **dimensioned three-quarter view** → side elevation →
rear view of the ventilation package → **top-down floor plan with the door swing**.

Lead with the exterior, always include at least one dimensioned view, always close with the
plan. The dimensioned views are SketchUp exports carrying SketchUp dimension entities.

## `proposal-v2.json` shape

```
client, docType, date, contact{phone,email,web}
cover { eyebrow, headlineLead, headlineLines, sub, image,
        captionLead, caption, cards[{label,value,sub}], calloutLead, callout }
sections[] { num, model, boothOf, extra, lead,
             plates[{ image, view, caption }] }
```

## Machine facts

- No poppler / `pdftoppm`. Rasterize for checking with **PyMuPDF (`fitz`)**.
- Puppeteer isn't installed locally. Print with **headless Chrome**.
- Python stdout is cp1252 — `sys.stdout.reconfigure(encoding='utf-8', errors='replace')`
  before printing extracted PDF text, or dimension marks (′ ″) crash the script.
- Target 2.5–3.6 MB. Don't ship full-resolution PNGs.
- The `-v2` is the *generator format* version. Never put "V2" in a client-facing filename
  unless it really is a revision.
